  1. Problem

    Doyensys support and its customers tracked incidents, service requests, change approvals and weekly status reports across email threads and documents. Nobody had one place to look, and one customer's data must never be visible to another.

    Approach

    A ticketing portal on Fastify, Prisma and PostgreSQL, with a 21-model schema. Tenant isolation is enforced twice: in the queries, and by PostgreSQL row-level security set per request through a single withTenantContext() function. Unread support emails become tickets over IMAP, but only when the sender matches a known customer, because a ticket filed under the wrong organisation is worse than no ticket.

    Details

    TypeScript, Fastify, Prisma, PostgreSQL RLS, Zod, JWT, Vitest, GitHub Actions

    GitHub repository →

    Approach

    Details

  3. Problem

    A US pet-products retailer sells through Amazon, Walmart and Shopify. Orders, catalogue and forecast data have to land in Oracle and Snowflake every day, correctly, for reporting. One morning ten days of Amazon orders, about 2,000 a day, turned out to be missing.

    Approach

    I traced the gap to a task flow that had been failing at a broken notification step, fixed it and backfilled the staging table. Alongside that I build and maintain five-plus Informatica pipelines, including a record-count alert so a silent failure gets noticed, a Pattern PXM API load covering 2,000+ product collections, and a JDBC feed of factory machine data from Ignition at 5-second intervals.

    Details

    Informatica Cloud, Snowflake, Oracle, Databricks, REST, OAuth, MicroStrategy

    Client work at Doyensys. Code is private.

  4. Problem

    ERP and CRM exports describe the same customers and products in different shapes, so sales questions that span both systems are slow and error-prone to answer.

    Approach

    A three-layer warehouse. Stored procedures load raw CSVs into Bronze, Silver cleans and standardises them, and Gold holds star-schema fact and dimension tables that analytical queries can hit directly.

    Details

    SQL Server, Medallion architecture, star schema, stored procedures

Background & capabilities

I came to full-stack work through data, and it shows in how I build.

I studied Computer Science with a Cyber Physical Systems focus at VIT Chennai, then joined Doyensys, where I work on data engineering for a US retail client. Lately I've been writing Go and reading about application security. Web apps, pipelines and security tooling ask for the same things: care with untrusted input, and software that behaves when something upstream breaks.
